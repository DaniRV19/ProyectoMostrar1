# 🎨 Nextly

Proyecto web centrado en el **diseño de interfaces y desarrollo frontend**, creado para explorar y demostrar mis habilidades en diseño visual, composición y experiencia de usuario.

El proyecto busca combinar una estética moderna con una interfaz cuidada, prestando especial atención a los detalles visuales, las animaciones y la interacción con el usuario.

## ✨ Características

- 🎨 Diseño de interfaz moderno y visual.
- 📐 Composición y jerarquía visual.
- 🖥️ Desarrollo de interfaces frontend.
- ✨ Animaciones y transiciones.
- 📱 Diseño responsive.
- 🧩 Componentes y elementos de interfaz reutilizables.
- 🖱️ Interacciones y efectos visuales.

## 🛠️ Tecnologías

`HTML` · `CSS` · `JavaScript`

## 🎯 Objetivo

Crear una experiencia web atractiva que me permita **experimentar con diseño, frontend y experiencia de usuario**, poniendo especial énfasis en la calidad visual y en los pequeños detalles que hacen que una interfaz resulte intuitiva y agradable.

## 💡 Enfoque

Nextly nace como un proyecto principalmente visual, orientado a **explorar ideas de diseño y mejorar mis habilidades en desarrollo frontend**, experimentando con diferentes layouts, estilos, animaciones e interacciones.
